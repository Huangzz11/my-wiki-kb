# 新传高频名词图卡

新传考研高频理论名词的可视化卡片系列，一律 1080×1440（3:4 竖版），署名「小鱼学新传」。

**两套版式**（2026-10-14 起并行，按名词所属栏目选，不要混用）：

| 版式 | 张数 | 特征 | 用在 |
|---|---|---|---|
| 单张卡（原版） | 5 | 无编号，直接进名词解析 | 日常收录 |
| **100 讲系列**（`templates/noun-100/`） | 3 | 封面 + 答案·上/下 | 编号连载 |

100 讲系列封面经历两版：**v1**（series-band 珊瑚铺面 + 白字、标题居中）、**v13**（2026-10-19 定稿：系列行改珊瑚文字 + 通栏发丝线、刊头去 spike 与日期、主标题左齐、页脚去上分隔线、无「右滑」提示行）。**现有成品统一走 v13**。答案页两版通用，用「线优先」版式（一条 1px 细框圈住全部答案）。讲次只出现在**画面内**，目录仍按名词名归档，不把讲次写进目录名——读者搜的是词，不是期号。

与 `kb/新传热点事件解读/` 并列：热点解读是「事件 → 理论」的案例分析，本目录是「纯理论名词」的知识点拆解。二者互为补充。

## 命名规范

- 目录：`kb/新传高频名词/<名词名>/`
- 文件：`<名词名>-0X.png`（X 从 1 起，两位数字）

## 维护

新增名词卡时：建同名目录 → 平铺图片（不建子目录）→ 本表补一行 → 更新 `kb/wiki/index.md` 的「新传高频名词」段 → 追加 `kb/wiki/log.md`。

图卡源文件（HTML / CSS / shoot.js）**不提交**，只提交 PNG。桌面副本可选（热点解读那边是 `Desktop/<编号>_<事件名>_图卡/`，本系列按需）。
