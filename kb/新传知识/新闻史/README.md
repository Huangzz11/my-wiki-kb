## 三、第一讲核心：11 条规律

**母题一 · 双重属性**
新闻媒体 ＝ 上层建筑属性（事业性、政治）＋ 信息产业属性（产业、盈利）
外在表现：事业性质、企业管理。政治上恪守党性原则，经济上按社会主义市场经济规则运行。

**母题二 · 事业二重性**
新闻事业 ＝ 社会性 ＋ 阶级性
- 社会性由三点决定：面向社会不特定大众；部分内容反映各阶级共同利益与共同生活；各媒体都追求社会公众的广泛认同。
- 阶级性由三点决定：传播主体与接受主体都代表一定阶级；媒体受国家与社会制度控制；媒体性质由经济基础性质决定。

### A · 上层建筑属性（6 条）

| 编号 | 性质 | 内容 |
|---|---|---|
| A1 | 社会性 | 诞生于特定时代背景，又反作用于社会发展 |
| A2 | 社会性 | 某个历史阶段的报刊具有一定共性 |
| A3 | 社会性 | 一定时代的新闻媒体起到传递时代信息与观点的重要作用 |
| A4 | 阶级性 | 特定媒体为特定阶级服务，体现阶级诉求 |
| A5 | 阶级性 | 办报方针反映办报主体的诉求与思想，随主体变化而变化 |
| A6 | 阶级性 | 统治阶级的传播制度会限制与约束被统治阶级的媒体 |

### B · 信息产业属性（5 条）

| 编号 | 内容 |
|---|---|
| B1 | 为盈利，制定符合传播规律的新闻方针 |
| B2 | 为盈利，改革新闻采写编评的流程 |
| B3 | 为盈利，更新产品形态、调整发行模式（如报纸开设副刊） |
| B4 | 为盈利，提升专业性、走向专业主义（《大公报》《纽约时报》） |
| B5 | 为盈利，也可能生出乱象（黄色新闻、垄断） |

> 编号 A1—A6 / B1—B5 为自编，讲义原文是两套各自从 1 起编的序号，两栏并存会撞号，故加字母前缀。

### 判类速查

| 报刊类型 | 主用哪侧 | 典型落点 |
|---|---|---|
| 外人办报 | A ＋ B | 殖民诉求看 A4／A6，商业信息看 B1／B3 |
| 改良派、革命派机关报 | A | A4 阶级诉求、A5 方针、A6 被查禁 |
| 政党报纸 | A | A2 阶段共性、A5 随政党立场转向 |
| 廉价报刊、大众化报刊 | B | B1 定价方针、B3 版面形态、B5 黄色新闻 |
| 通讯社 | B | B1 客户定位、B2 采编流程标准化 |

### 三步套用法

1. **定性**：机关报走 A 线，商业报走 B 线，两者兼具则两条都写。
2. **切片**：词条切成四块——创办背景 / 宗旨 / 内容与业务 / 历史评价。
3. **挂钩**：每块挂一个编号，写成「因为规律 X，所以该报表现为 Y」。

## 四、两张大地图

### 中国新闻史：革命史思维（15 章）

分期：封建时期 → 革命时期 → 建设时期 → 改革时期。主线是**办报主体的阶级递进**：

外人办报 → 资产阶级改良派 → 资产阶级革命派 → 政党报纸 → 无产阶级萌芽 → 建党与大革命 → 十年内战 → 抗战 → 解放战争 → 社会主义改造与建设 → 文革 → 改革开放 → 台港澳

### 外国新闻史：全球史五段（20 章）

封建集权 → 资产阶级转型 → 市场竞争 → 社会主义 → 互联网时代

资产阶级转型六条路径：渐进改良（英）/ 起伏曲折（法）/ 突进平坦（美）/ 二元变通（日德）/ 邪恶异化（德日意西法西斯）/ 外部植入（二战后美占区改造）
