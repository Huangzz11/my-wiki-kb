# 新传知识（学科知识区）

新传考研**专业课学科知识**的结构化沉淀区。与 `kb/新传热点事件解读/`、`kb/新传高频名词/` 的区别：

| 目录 | 定位 | 产物 |
|---|---|---|
| `新传知识/`（本目录） | 学科体系的**骨架与工具**：分期脉络、分析框架、答题模板 | 复习卡片 + 索引笔记 |
| `新传高频名词/` | 单个**理论名词**的可视化拆解 | 1080×1440 图卡 |
| `新传热点事件解读/` | **事件 → 理论**的案例应用 | 笔记 + 图卡 |

一句话：热点是「用理论解事件」，名词卡是「拆开一个概念」，本区是「把整门课串成一张网」。

## 收录规则

1. **只收自己产出的结构化笔记与卡片**，原课程讲义 PDF 不入库（版权归属课程方，且单份 2—3 MB 会撑大仓库）。原讲义存放在本地 `桌面_考研资料/04_新闻史/`。
2. 每门课一个子目录，目录内放一个 `README.md` 作索引，含：文件清单、学习进度、核心框架速查。
3. 卡片统一 A4 单页可打印，命名 `<讲次>-<主题>.pdf`，同名 `.html` 并存（网页版便于手机阅读）。
4. 新增子目录后，同步更新本 README 的「子目录」表、`kb/wiki/index.md` 的「新传知识」段、`kb/wiki/log.md`。

## 为什么要这块地方

热点图卡能带来流量，名词卡能补细节，但两者都建立在「你已经知道这门课怎么分期、用什么框架分析」的前提上。新闻史 15 章、外新史 20 章这种体量，缺了骨架就是硬背。本区存的就是骨架。
