# 考研每日反馈

知栀的每日考研学习反馈归档。每天一份，记录政治 / 英语 / 专业课三科的错题、知识点与反思。

## 收录规则

- 一天一份，文件名 `YYYY-MM-DD-<主题>.md`。
- 内容来自当天的原始 docx，经 `kaoyan-feedback-polish` skill 优化后转为 Markdown。
- **原文 100% 保留**（含错别字），订正只以批注形式出现，不改动原字。
- 截图导出到同名 `_assets/` 目录，按 `img01.png` 顺序编号。

## 标注约定

| 标记 | 含义 |
|---|---|
| `**加粗**` | 原文档的**下划线** —— 需要背诵 / 重点掌握 |
| `<mark title='易错'>` | 原文档黄色高亮 —— 易错点、关键考点 |
| `<mark title='次重点'>` | 原文档青色/绿色高亮 —— 复杂内容、次要考点 |
| `<mark title='框架'>` | 原文档浅灰高亮 —— 框架性、结构性内容 |
| `<mark title='陷阱'>` | 原文档红色高亮 —— 易混陷阱 |
| `> ` 引用块 | AI 补充内容（原文档为楷体+深蓝），**不是**用户原文 |
| `✎` 行 | 拼写 / 释义订正提示，**原文未改** |
