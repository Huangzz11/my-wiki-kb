# Source: 三概念关系说明

## Summary

对 [[Agent]]、[[Context]]、[[Skill]] 三者关系的个人化梳理：Agent 是干活的人、上下文是工作台、Skill 是作业指导书（另补充 [[LLM]] 为大脑）。上下文决定 Agent 每次决策的信息边界；Skill 给 Agent 跨越时间的可复用方法；两者通过"渐进式披露"衔接。

## Key Claims

- 上下文是 Agent 唯一的现场记忆——忘了就等于没发生。
- 上下文信息质量 = 决策质量下限，上下文管理是 Agent 工程的核心难题。
- Skill 是 Agent 的程序性记忆（团队经验外部化），可版本管理、随仓库分发。
- 渐进式披露使"装很多 Skill 也不撑爆上下文"成为可能。
