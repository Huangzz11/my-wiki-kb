# Entity: llm-wiki-agent

开源项目（SamurAIGPT 组织，MIT 协议，约 3.5k star）：让编码 Agent 自动维护个人知识库的"技能包"。仓库链接：https://github.com/SamurAIGPT/llm-wiki-agent

在本知识库中的作用：[[SelfMaintainingWiki]] 范式与 kb/ 目录结构、ingest 工作流、页面规范（frontmatter + `[[双链]]`）的直接来源。其核心设计分析见 [[sources/llm-wiki-agent-report]]。
