# Entity: Anthropic

美国 AI 实验室，Claude 系列模型开发商，[Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) 规范与《Building Effective Agents》等工程范式的重要来源。

在本知识库中的作用：[[Agent]]（工作流 vs Agent 划分）、[[Skill]]（Agent Skills 规范）、[[LLM]]（Claude 系列）等多个概念的一手参考方；[[LLMWikiAgent]] 所驱动的 Claude Code 亦出自该公司。

**[[MultiAgentTeam]] 的主要一手数据来源**：其工程博客《How we built our multi-agent research system》公布了主编 Opus 4 + 子 agent Sonnet 4 比单用 Opus 4 高 90.2%（内部 research 评测），并说明 BrowseComp 上 token 用量单独解释 80% 的性能方差、多 agent 约耗 15 倍 token。这也是本库关于"多 agent 的优势主要是算力优势"这一判断的依据。
