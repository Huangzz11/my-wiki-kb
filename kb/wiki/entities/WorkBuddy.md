# Entity: WorkBuddy

在本知识库中的作用：concept-learner 与 wiki-keeper 两个项目级 Skill 的运行环境；与 [[LLMWikiAgent]] 面向的 Claude Code/Codex/Gemini CLI 生态形成对照——文件驱动的 Agent 范式在 WorkBuddy 中的落地。
