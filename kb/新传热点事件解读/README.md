# 新传热点事件解读

面向新传考研的热点案例分析库。每期一个事件，固定结构：

**事件回顾 → 新传视角解析（5 个理论点）→ 考点金句 → 同源案例 → 小红书文案 → 资料来源**

每期同时产出 **3–6 张 1080×1440（3:4）竖版图卡**，按小红书规格制作，可直接发布。图卡存于 `images/`，命名规则 `编号-事件名-序号.png`。

版式：编号 12–14 为绿色系卡片版式；编号 15–17 为宝厂黑白长图文版式（白底 + 超粗黑标题 + 粗下划线），编号 16 起首页加反白通栏刊头「九月热点事件案例分析」（同批次共用）；**编号 18 起按用户 2026-09-21 要求切换回绿色卡片版式**（绿版、白底 + 主色 `#12a45c` + 页头居中大标题 + 底部渐变色条），底色与 12–14 一致。切换版式时直接复制上一期同版式目录下的 `style.css` 与 `shoot.js`，改 `DIR` 与 `pages` 即可，不要混用两套样式。

**Anthropic 风格版式（2026-09-24 新增）**：编号 20 另出一套参照 anthropic.com 实测参数的版式，文件名加 `-anthropic` 后缀（如 `20-永和豆浆擦边-anthropic-01.png`），内容与绿版完全一致。色板取自官网 `:root` 变量实测：底色 `#faf9f5`、次级底 `#f0eee6`、分隔线 `#e8e6dc`、正文 `#141413`、主强调 `#d97757`、次强调 `#c6613f`。字体为官网 `Anthropic Sans` / `Anthropic Serif`（本地副本，仅覆盖拉丁字母，**中文字形数为 0**，中文回落思源宋体/黑体 SC）。绿版作为原始版本保留，两套并存。合规范式与抓取方法见用户级 skill `minimalist-ui` 第 3.0 与 4.1 节。

## 收录规则

- 编号连续，不跳号；每期一个 Markdown 文件，不按理论或媒体拆碎。
- 事件事实必须交叉核对 ≥2 个独立来源；只有一个来源的细节标注「单来源待核」。
- 来源之间存在分歧时，两方表述都保留在文末「待核项」，不擅自取舍。
- 每条解析必须落到具名理论上，不写只有情绪没有理论的评论。
- 图卡源文件（HTML/CSS）不随仓库提交，需要改版时在本地重新生成。

> **道德灰区 + 口径缺口双重题材（编号 29，2026-10-03 祁连腾宿舍安置游客）**：当地方应急善意与第三方群体的程序权益**同时成立**、且官方口径回避了核心环节时，两条规范叠加使用。具体做法：① 善意与担当必须写到位（游客带老人小孩、零下4℃、通宵值守、局长一线铺床），只写质疑既刻薄也失真；② **不做「未经同意」的事实性断定**——公开报道无此确认、官方回应为「会沟通」，笔记只写「官方未提供事前告知的明确信息」，并列入待核项首位；③ **核查要主动找「结构性证据」**：本期最硬的一层是「宿舍启用本就写在应急预案之内」，它把「来不及告知」这个理由直接证伪，也是全部评论里差异度最高的一条；④ 剔除对一线人员的动机揣测（「作秀」「蹭流量」「慷他人之慨」），并保留官方原话的完整引述（如冯玲玲关于 2.3 万张床位与「储备地方也还有」的自述不可只截半句）；⑤ 落点放在**流程设计**上，不放在「该不该腾」的价值站队上。
